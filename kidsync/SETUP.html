5 Quick Start Guide

For Parents:

  • Login or register a new account
  • View dashboard with your children's information
  • Monitor live location and activities
  • Communicate with teachers via messaging

For Teachers:

  • Login to teacher portal
  • View all students in your school
  • Add grades, mark attendance, generate report cards
  • Send messages to parents

For Child Device Simulation:

  • Access device with child ID and token
  • Simulate movement (Home → Bus → School)
  • Add activities that sync to parent dashboard
  • Watch live location updates
